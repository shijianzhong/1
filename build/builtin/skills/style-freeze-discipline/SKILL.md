# 风格固化纪律（A3 content-stylist）

阶段3风格固化按本纪律跑。把阶段2拆出的"所长" + 样文库的翘楚样文，综合回填进风格画像。固化后每次产出套用，风格稳定可复。

## 综合输入

- 阶段2 `benchmark-discipline` 的四维拆解结论（标题公式/结构模板/互动钩子）
- 样文库代表作：调 `sample_article_read` 读已存的翘楚样文正文
- 本号历史产出（如有）：读已有风格画像，在其上滚动更新而非推倒重来

## 回填风格画像

调 `style_profile_update` 工具，写入以下字段：

### 标题公式（titleFormulas）
从四维拆解的"标题公式逆向"提炼 3-6 个可套用公式，每条写成"公式 + 规则"：
- 冲突+转折+数字：他 35 岁被裁，副业月入 10 万
- 反常识+颠覆：AI 写公众号反而更耗时间？
- 故事+真实细节：我做公众号第 137 天，单篇 27 万阅读
- 极短口语型：又一个神级 skill 火了，没废话。（10-15字，适合痛点共鸣强）

### 6段式骨架（structureSkeleton）
提炼可复用结构模板，字数参考非硬卡：
- 钩子 50-100（反差/故事/数据开头，3秒抓趋势）
- 引入 100-150（背景：这事为什么重要）
- 痛点展开 300-500（读者真正的问题在哪）
- 干货方案 500-800（方法/对比/选型，核心信息密度）
- 真实案例 200-400（"我用了之后…"带具体数据）
- 总结+互动 100-200（金句转发点 + 文末具体问题）

### 语气词表（toneWords）
- 用：说白了/其实就是/踩了个坑/我实测/别急着/这才
- 戏称可用：电子牛马、一本正经胡说、给agent装脑子

### 字数区间（wordCountRange）
核心标准是"3秒抓趋势+废话少+清晰明了"，不是字数。判断型/科普型 1500-2000 说清即停，实测型/技术拆解型 2000-3000。**绝不卡下限硬撑**——早期2500是防"500字罗列"的防呆线，风格已固化后松绑。底线：短而清楚OK，短而浅/短而水不行。

### 互动钩子模板（interactionHooks）
文末留一个具体的、读者答得上的问题：
- ✅ "你的 agent 现在用的是 RAG 还是知识图谱？卡在哪个查询上？"
- ❌ "你怎么看？"（太空，没人答）

### 自造说法禁用清单（bannedInventedTerms）
从样文+拆解中提炼本方向要避开的自造说法（见 review-discipline §2.5 根源A）：
- 抽象红利/潜能：释放红利、激发潜能、势能动能
- 商业黑话动宾：打通全链路、串联生态、沉淀闭环
- 阶段化隐喻：进入新纪元、迈向下半场
- 抽象容器词：信息茧房、认知壁垒、能力天花板

### 英译式连接词禁用清单（bannedEnglishConnections）
提炼要逐句审的连接词（见 review-discipline §2.5 根源B）：
反映出 / 体现出 / 表明了 / 揭示了 / 这意味着 / 由此可见 / 不难看出 / 充分说明

## Discipline

风格画像必须六字段齐全（标题公式/骨架/语气词/字数/互动钩子/两个禁用清单），不能只填一两个。固化是"综合众家所长"非照抄单个号。固化后产出必套用，不每篇漂移。禁用清单（自造说法+英译连接词）是产文时 ai_cavity_audit 的前置规则库，必须回填。
