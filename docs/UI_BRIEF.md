# One — UI 实现简报（纯白通透玻璃态）

> 给编码 AI 的视觉实现简报：基于 [`DESIGN.md`](./DESIGN.md) 的设计令牌，把下面这些屏幕"长成这样"。这不是出图提示词，是要你**写 React/CSS 实现**的目标视觉——颜色全走 DESIGN.md §2.1 的 CSS 变量，玻璃元素走 `--glass-*`，正文走 `--color-bg-1`。
>
> **铁律（贯穿所有屏幕）**：玻璃做容器与悬浮，实色承载正文/代码/表格。改组件时若出现"为某主题加 if/else"，转成 CSS 变量。
> **已无登录页**（开源个人桌面工具，单用户，开机即用）。
> **主题可自定义**：所有视觉走 CSS 变量，主题切换 = 变量覆盖，组件代码零改动；用户可换点缀色、调玻璃、换背景图。详见 DESIGN.md §十二。

---

## §0 视觉基调（实现时以此为基准）

- 画布：`var(--color-bg-0)` 纯白通透冷调（`#FCFCFD`，不黄不暖）。
- 玻璃面板：`background: var(--glass-bg); backdrop-filter: blur(var(--glass-blur)); border-top: 1px solid var(--glass-border-top); border-bottom: 1px solid var(--glass-border-bottom); box-shadow: var(--glass-shadow);`。
- 点缀色：`var(--color-brand-500)` 薄荷绿 `#4ECDC4`，只在主操作/激活态/高亮/focus ring 处使用，大面积克制。
- 文字：主 `var(--color-fg-1)` 深墨灰、次 `var(--color-fg-2)` 冷灰、占位 `var(--color-fg-3)`。
- 投影/描边一律冷调（`--glass-shadow`、`--color-border`），禁止暖黄/奶油/米色。
- 无强渐变、无荧光、无噪点装饰。气质：干净、通透、舒展、眼前一亮又淡雅自然。

## §0.1 布局骨架（贯穿所有屏幕）

实现为 `App.tsx` 的根布局：
- 最上 `TitleBar`（40px 固定磨砂玻璃横栏，作为窗口标题栏缓冲带与全局顶部信息层；左侧为页面标题/应用名，右侧可放 `CommandPalette` 入口或轻量动作）。
- 最左 `IconRail`（56px 固定磨砂玻璃竖栏，竖排图标：首页/画布/角色/技能/模型/任务/设置，激活项 `brand-500` 左条 + `bg-3` 高亮）。
- 紧邻 `SideList`（220px 可折叠会话/能力列表，仅"首页聊天"态展开，画布/管理/设置/任务态均隐藏收回空间）。
- 主工作区 `MainArea`（占满剩余，承载聊天流/画布/列表/设置，按路由切换）。
- 右侧 `Inspector`（浮动磨砂玻璃面板，仅画布选中节点时从右滑入 420px；不选中即收起，不占固定空间）。
- `CommandPalette`（⌘K 悬浮磨砂玻璃居中弹层）作为统一导航/搜索/动作入口。
- **窗口标题栏**：macOS 用 `titleBarStyle: 'hiddenInset'`，红黄绿按钮落在最顶 `TitleBar` 这一行；`TitleBar` 整体为 `-webkit-app-region: drag`，按钮/输入区 `no-drag`，并在左侧预留 traffic light 空间，避免压住标题。Windows/Linux 可继续用默认标题栏，或在 `TitleBar` 右侧自绘最小化/最大化/关闭按钮。详见 REWRITE_PLAN §六。

## §1 首页主助手聊天

- 布局：`IconRail` + `SideList`（最近会话与收藏，当前会话高亮，留白舒展）+ `MainArea` 居中聊天流最大宽 760px，背景 `--color-bg-0`。
- 用户气泡：右对齐，实色 `--color-brand-500` 填充，白色文字，大圆角，右下角方角。
- AI 气泡：左对齐，**实色** `--color-bg-1`（厚白）+ `--color-border` 细描边，承载 Markdown。气泡是"内容"不是"框"，用实色保证文字对比度（铁律：玻璃是框，实色是内容）。
- 代码块：实色 `--color-bg-2` 无边框 + 右上角复制 ghost 图标 + `--font-mono` 深墨灰；行内代码 `--bg-3` 小圆角；引用块左侧 `--brand-500` 细条。
- 头像：28px 圆，AI 用 `--brand-500` 底 + 星光图标，用户用首字母。
- 流式光标：AI 文本末尾闪烁细竖线 `▋`（`animate-pulse` 1s），生成结束消失。
- 底部输入区：横贯磨砂玻璃长条（`--glass-bg-strong` + 顶部高光），内含胶囊输入框 + `--brand-500` 发送按钮。
- 工具调用：折叠卡片嵌在 AI 气泡内，折叠态"🔧 工具名 → 已完成"，展开显示参数 + 结果代码块（实色底）。

## §2 能力编排画布（核心，ReactFlow）

- 布局：`IconRail`；画布态 `SideList` 收起，`MainArea` 几乎全宽。
- 画布背景 `--color-bg-0` + 极淡冷灰点阵网格（点几乎隐入）。
- `Inspector`：选中节点时从右滑入（420px，`--glass-bg` + `--glass-blur-strong`），Tab（配置/工具/运行日志）；不选中收起。
- 左侧浮动 `NodePalette`：可折叠磨砂玻璃面板，拖拽预览用半透明节点幽灵。
- 节点卡片：磨砂玻璃（`--glass-bg` + `--glass-blur` + 顶部高光描边 + 4px 顶部拖动条 + `--glass-shadow`）。
- 六类节点视觉（`executor_id` == ReactFlow 节点 id，运行态 `--brand-500` 脉冲描边）：
  - **agent**：玻璃圆角矩形 + 机器人图标 + 名称 + 模型小字。
  - **sequential**：竖向虚线玻璃容器标"序"。
  - **concurrent**：横向虚线玻璃容器标"并"。
  - **groupchat**：圆角玻璃容器标"群聊"，当前发言者高亮。
  - **handoff**：节点间贝塞尔箭头 + 条件标签胶囊，激活路径 `--brand-500`。
  - **magentic**：Leader 居中、Worker 环绕、虚线辐射连接（MVP 可跳过）。
- 连线：默认 `--color-border`，激活 `--brand-500` 加粗。

## §3 管理后台列表（角色/技能/模型/能力）

- 布局：`IconRail`；管理态 `SideList` 收起。`MainArea` 居中内容最大宽 1200px。
- 顶部工具条：磨砂玻璃长条（`--glass-bg` + 顶部高光），内含胶囊搜索框、筛选标签、右侧 `--brand-500` "新建"主按钮。
- 表格：行无分割线，hover 整行浮起 `--glass-bg` + `--bg-3` 高亮。表头小字大写字距加宽 `--fg-2`。
- 每行：前置图标 + 名称 + `--fg-2` 元数据 + 后置 ghost 图标操作（仅 hover 显现）。
- 空态：居中细描边图标 + 一行 `--fg-2` 说明 + 主操作按钮。
- 加载态：5 行骨架 `--bg-3 animate-pulse`。
- 点击行打开右侧 600px 磨砂玻璃抽屉，内含分节表单卡片（表单卡片实色 `--bg-1` 保证可读）。

## §4 设置页

- 布局：`IconRail`（设置项激活）+ `MainArea` 两列。
- 左列二级导航：磨砂玻璃竖条，导航项 ghost 样式，激活项 `--brand-500` 左条 + `--bg-3` 高亮。
- 右列 720px 内容。
- 设置分组进磨砂玻璃分节卡片，标题中等字重 + 标题下细描边。每行高 48px + 底部细描边：左标签 + `--fg-2` 说明，右控件。
- 分区：个人档案（称呼/角色描述/偏好语种——L0 身份块来源）、外观（主题预设网格/明暗模式/点缀色/背景图/玻璃/密度/字号，实时预览，详见 DESIGN.md §12.6 + §12.6.1）、LLM 配置（中转地址、API key 密码输入框、默认模型下拉——本地单用户无登录）、快捷键（kbd 芯片）、开机自启（开关）、关于（版本、检查更新）。
- 玻璃只做容器与分区，表单内容实色保证可读。

## §5 任务进度页

- 布局：`IconRail`（任务项激活）+ `MainArea` 居中最大宽 900px。
- 顶部磨砂玻璃条：运行标题 + 状态徽章（运行中 `--brand-500`、完成 `--color-success`、失败 `--color-danger`）+ 用时。
- 纵向时间线，每节点一条玻璃卡片行：图标 + 名称 + 状态点 + 时长 + 展开箭头。
- 当前运行节点：`--brand-500` 脉冲左侧细条 + 实时 token 流预览（最后一行等宽 `--fg-2`）。
- 展开日志：等宽代码块（实色 `--bg-2` 底），工具调用/结果对缩进。
- 顶部进度条 `--brand-500` 填充。失败节点内联错误卡片 + 重试按钮。

## §6 命令面板（⌘K，贯穿全局）

- 居中悬浮磨砂玻璃面板，从顶部下拉淡入。
- 背景全屏罩极淡冷色遮罩（`var(--overlay-bg)` + 背景模糊）。
- 面板：`--glass-bg` + `--glass-blur-strong` + 顶部高光描边 + 大圆角，宽 640px。
- 顶部胶囊搜索框（占位"跳转到… 或问 AI"），下方分组结果：导航/动作/最近会话/能力。
- 每行：细描边图标 + 标题 + `--fg-2` 副标 + 右侧 kbd 芯片。
- 键盘上下选择，回车执行，Esc 关闭。结果项 hover 浮起更亮玻璃，选中项 `--brand-500` 左条。

## 实现约定

1. **颜色全走 CSS 变量**（`--color-*` / `--glass-*`），无硬编码 hex/rgb。玻璃元素一律走 `--glass-*`。
2. **正文/代码/表格用实色 `--color-bg-1` / `--bg-2`**，不用 `--glass-bg`（玻璃是框，实色是内容）。
3. **新组件在纯白/暖白/夜色三套预设下都校准对比度**（DESIGN.md §2.3 + §十二），不依赖单一主题。
4. 节点标签作为 i18n 资源：zh-CN 用中文（序/并/群聊），en 用英文（SEQ/PAR/GROUP），跟随 UI 语种切换（见 REWRITE_PLAN §十二.2），不写死。
5. 流式生成用光标、无抖动；动效在 `prefers-reduced-motion` 下关闭。
6. 布局骨架（`TitleBar` + `IconRail` + `SideList` + `MainArea` + `Inspector` + `CommandPalette`）在 `App.tsx` 根布局统一实现，各屏幕只填 `MainArea` 内容。
